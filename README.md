# 한신초등학교 춘추복 3D 캐릭터 체험

무료 정적 웹 앱입니다. 스마트폰 카메라 또는 체험 모드로 춘추복 3D 캐릭터를 확인할 수 있습니다.

## 구성
- `index.html` : 메인 페이지
- `js/engine.js` : 로컬 WebGL 렌더러
- `js/avatar.js` : 춘추복 3D 캐릭터 모델 및 애니메이션
- `assets/school-badge.png` : 학교 배지 이미지

## 사용 방법
1. GitHub Pages 또는 HTTPS 정적 호스팅에 전체 파일 업로드
2. 스마트폰에서 접속
3. `카메라 시작` 또는 `체험 모드` 실행

## 특징
- 별도 서버 없음
- AI API 비용 없음
- MediaPipe Pose Landmarker를 CDN에서 불러와 포즈 추적
- 포즈 추적이 실패하면 체험 모드로 계속 사용 가능

## 주의
- 카메라 사용은 HTTPS 접속에서만 동작합니다.
- `실제 얼굴 사용(베타)`는 얼굴 분리 AI가 아닌 원형 크롭 방식입니다.
- 본 앱은 시제품이며, 실제 교복의 완전한 3D 복제는 아닙니다.
